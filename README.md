# SeisAssist

Landing responsive académica del equipo Nodus. La página principal es [pages/index.html](pages/index.html).

- [Instrucciones, créditos y guía de repositorio/Pages](docs/README.md)
- [Auditoría y resultados](docs/auditoria.html)
- [Código completo para copiar](docs/codigo_completo.html)
- [Matriz de 30 HU](docs/matriz_30_HU.csv)
- [Casos de aceptación para Pages](docs/casos_aceptacion.csv)

HTML, CSS y JavaScript sin compilación. Publicar la rama `main`, carpeta `/(root)`; la entrada raíz redirige a `pages/index.html`.

Utiliza únicamente datos ficticios. Los estados SOS, recepción y radar son demostraciones locales: no envían auxilio ni operan una red Bluetooth Mesh. La copia offline necesita una primera visita por HTTPS o localhost.
